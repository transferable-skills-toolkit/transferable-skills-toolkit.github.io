    How suggestions work

    The toolkit follows a short set of fixed rules. Nothing is generated or guessed: every suggestion comes from one of the tables below, and you can change any of it before you copy.

    1. Your assessment type pre-selects its usual sub-headings, each with up to two statements highlighted. If two suggestions share a sub-heading, the first two statements are kept.
    2. Each thing you tick in step 2 adds one more sub-heading. The marker shows which tick added it.
    3. "Also worth considering" lists optional sub-headings for that type. They are only added if you choose them.
    4. You decide. Untick a marker, change its statements, or add any of the 37 sub-headings yourself. Statements are always quoted word for word from the Transferable Skills Language.

    The same rules are in the AIS Skills Markers spreadsheet, where you can see and edit the pre-selected skills for every assessment type. Suggested changes to the rules are welcome.

      Writing markers that students can use

      Each marker names a skill (the Skills Language sub-heading) and the skill area it belongs to, then lists what students will do, using statements quoted exactly from the framework. Students can find the same words on the University's Skills Language pages and borrow them for CVs, applications and interviews.

      A good marker

      • Keeps the framework wording. Choose the statements that fit; don't rewrite them.
      • Uses one or two statements. More than that is hard for students to take in.
      • Says how students show it in this task, in the optional How line.
      • Matches the marking. If nothing in the rubric or task rewards it, leave it out.
      • Traces back to an ILO. Every marker should support one of the course's intended learning outcomes.

      Writing a good How line

      The How line turns a general statement into something a student recognises in this task. Point to a part of the assessment and say what they do there.

      How markers, ILOs and rubrics fit together

      1. ILOs say what students will be able to do by the end of the course. They are approved in the PIP.
      2. Rubric criteria mark each ILO in a specific task.
      3. Markers tell students which Skills Language skills those criteria reward, in words they can reuse.

      If a marker has no ILO or rubric criterion behind it, either leave it out or ask whether the ILO should mention it. The ILOs tab can help with that check.

      Common questions

      A skill is practised in the task but not marked. Should it be a marker?
      Usually not. Markers should point to what students are assessed on. If the skill matters, consider adding a line for it to the rubric.
      How do I handle group work?
      Only add Teamwork and collaboration if the group process is assessed, for example through peer assessment or a reflective account. A group output marked as a single product usually credits the content skills, not teamwork.
      How many markers should I use?
      Three to six. Fewer than three undersells most tasks; more than six becomes a list students skip.
      Can I change the framework wording?
      No. Keep the statements as written so students can find them on the Skills Language pages. Put task-specific detail in the How line.
      Do I need a How line for every marker?
      It is optional, but it is what makes a marker meaningful to students. Aim to add one for at least the markers that are least obvious.
